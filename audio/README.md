# Audio azan (Meta Didik)

Letakkan rakaman azan yang mempunyai kebenaran penggunaan di folder ini:

- `azan.mp3`: azan untuk Zohor, Asar, Maghrib dan Isyak
- `azan-subuh.mp3`: azan Subuh (pilihan; jika tiada, `azan.mp3` digunakan)

Cadangan: rakaman muazzin surau atau masjid sekolah sendiri, atau rakaman rasmi dengan kebenaran pemiliknya. Format MP3 mono 64 kbps sudah memadai (kira-kira 1.5 MB bagi 3 minit).

Jika fail tiada, Meta Didik memainkan bunyi beduk tradisional sebagai tanda masuk waktu.
