Cara guna (5 langkah)
  1. Tekan Muat soalan.json dari laman (jika fail ini berada di folder yang sama dengan permainan) atau Buka fail soalan.json daripada komputer anda.
  2. Cari soalan, klik untuk membukanya, ubah teks, pilihan atau jawapan betul. Gunakan Gantung jika mahu menyimpan soalan tetapi tidak digunakan dalam permainan. Gunakan Padam untuk membuangnya terus.
  3. Tambah soalan baharu dengan Soalan baharu, atau tambah banyak sekali gus melalui Import CSV (Excel atau Google Sheets, simpan sebagai CSV UTF-8). Muat turun Templat CSV untuk melihat susunan lajur.
  4. Semak lencana merah (soalan tidak sah, akan diabaikan oleh permainan) dan kuning (amaran: perlu disemak).
  5. Tekan Eksport soalan.json, kemudian muat naik fail itu ke GitHub (gantikan soalan.json lama di sebelah index.html). Murid mendapat soalan baharu apabila membuka permainan semula. Tiada perlu ubah index.html.

Setiap soalan ada ID tetap. Padam soalan tidak mengganggu rekod murid. ID baharu diberi secara automatik. Draf anda disimpan dalam pelayar ini sehingga dieksport.
